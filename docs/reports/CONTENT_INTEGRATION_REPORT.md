## G. Storage and preservation

The existing `LexoraDB` name, vocabulary primary keys, review log relationships, daily sessions and settings are retained. Dexie version 2 **only adds** a `contentCache` store (`key`, `retrievedAt`). No clear/delete/reset migration exists.

Saved dictionary words live in the existing `vocabulary` store with status `new`. Lookup alone only writes source cache data; it does not add vocabulary or review logs. Concurrent dictionary saves run in a transaction and return an existing normalized headword rather than overwriting it.

Explicit enrichment adds `dictionaryData` separately. It does not replace user definitions, Turkish meanings, personal notes, progress or SRS state. Tatoeba examples append to the existing examples array, deduplicating IDs and sentence text. Existing vocabulary editing now retains added metadata and unchanged example IDs/credits. If a translation is edited, the original translation credit is dropped to avoid misattribution.

The initial seed-data operation is now transactional to prevent two StrictMode initialization effects from inserting the same seed records simultaneously. Existing nonempty libraries are not reseeded. Reading texts and the small Tatoeba selection are bundled source assets, not user records.

## H. Offline scope

Verified in an isolated browser: saved vocabulary and cached dictionary data remain accessible after reload, without source-network access. An uncached offline lookup gives a useful connection error. The bundled reading passages, winter sentence selection and Special Elite/VT323 font files require no third-party content requests once the app assets are loaded or served locally. Existing IndexedDB learning data remains local.

**This is not a fully offline-installable application.** There is no service worker/app-shell cache. Offline startup away from a running local server is not verified. First-time dictionary/Tatoeba requests and remote pronunciation audio require internet; audio files are not cached. Existing pixel fonts still use the established Google Fonts stylesheet.

## M. Limitations / additional setup

- No provider account, API key or paid setup is needed.
- Live Dictionary API availability is the outstanding external limitation. Actual pronunciation playback and a successful live reading-word→dictionary→save cycle could not be confirmed while the endpoint timed out. Native audio controls and shared save flow passed recorded-response checks, but playback success is not claimed.
- No new translation generator, multiple-choice engine or exercise redesign was added. This project has a Writing Studio and six Flashcard modes; saved external sentences integrate with the existing sentence-context mode. Other modes retain their existing logic.
- Tatoeba suitability uses source approval/ownership, direct links, recognized licenses, length and whole-word matching, plus user review before saving. This is not a guarantee of every contributor's grammar/translation quality.
- The reading collection is intentionally two excerpts, not full books. Difficulty is labeled as an estimate, not certified CEFR.
- New caches are not a separate backup/export feature; saved vocabulary still travels with the existing database export. Native remote audio is online only. The complete application has not been certified offline.
